 Crop Recommendation Platform for AP Farmers

## Project Description
This project helps farmers in Andhra Pradesh
choose suitable crops based on soil and
environmental conditions.

## Objectives
- Help farmers select suitable crops.
- Provide simple crop recommendations.
- Create a user-friendly website.
- Support farmers with useful information.

## Technologies Used
- Python
- Streamlit
- HTML/CSS (for styling, if used)

## Project Files
- app.py: Main Streamlit application.
- crop_data.py: Crop-related data.
- recommendation.py: Crop recommendation logic.
- style.css: Website styling.
- assets/: Images and other resources.
- requirements.txt: Python dependencies.

## How to Run
1. Install Python.
2. Install project dependencies.
3. Open the project folder in VS Code.
4. Run the command:

   python -m streamlit run app.py
